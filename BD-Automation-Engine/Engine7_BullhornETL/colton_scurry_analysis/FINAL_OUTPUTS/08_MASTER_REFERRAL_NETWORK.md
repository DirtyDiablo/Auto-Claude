# MASTER REFERRAL NETWORK DATABASE

**Purpose:** Relationship mapping of all contacts extracted from 401 notes
**Use:** Name-drop referrals when reaching out to new contacts

---

## HOW TO USE THIS DATABASE

When reaching out to a contact:
1. Look up the contact in this database
2. Find their connections (reports to, works with, referred by)
3. Use the referral when reaching out

**Example Email:**
> "Hi Tom, Rob Whitt and Brenden Shishido mentioned you're the Chief Engineer on JTAGS..."

---

## RELATIONSHIP TYPES

| Symbol | Meaning |
|--------|---------|
| → | Reports to / Works under |
| ↔ | Works with / Peer |
| ⟶ | Referred / Introduced |
| ★ | Key Decision Maker |
| ● | PTS Placement (current/former) |
