## NOTES ON METHODOLOGY

### Data Limitations
1. **Subaward API Issues**: Direct subaward obligation data collection failed due to API connectivity issues with USASpending.gov
2. **Estimation Method**: Used prime contract value with 20-40% subaward flow-through assumption based on contract type:
   - Weapons production: 20-30% subaward
   - Services contracts: 30-50% subaward
   - IT services: 40-60% subaward (labor-intensive)
3. **Active Account Exclusions**: Based on Bullhorn CRM placement data showing 27 active contractors

### Recommendations for Data Enhancement
1. Re-run subaward data collection when API is stable
2. Cross-reference with SAM.gov small business subcontracting plans
3. Monitor FPDS for new task order awards under IDIQ vehicles
4. Track competitor hiring to identify hot programs
