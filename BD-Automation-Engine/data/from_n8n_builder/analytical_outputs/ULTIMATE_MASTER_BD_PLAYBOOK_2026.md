# SECTION 12: CALL SCRIPTS & OBJECTION HANDLING

## Opening Script - Cold Call
```
"Hi [Name], this is [Your Name] from PTS - we specialize in cleared IT
staffing for federal programs. I noticed you're supporting [Program]
with [Prime]. We've placed over [X] contractors with [Prime] and I wanted
to see if you have any hard-to-fill positions we could help with."
```

## Opening Script - Warm Lead
```
"Hi [Name], this is [Your Name] from PTS. We spoke [timeframe] ago about
[topic]. I'm following up because we've recently placed [relevant success]
and wanted to see if you have similar needs right now."
```

## Objection: "We have our own recruiters"
```
"I completely understand. We're not looking to replace your internal team -
we're a force multiplier. For those hard-to-fill TS/SCI roles where time is
critical, we can provide candidates in 48-72 hours. Would it make sense to
keep us as a backup option when speed matters?"
```

## Objection: "Send me an email"
```
"Happy to send info, but quick question first - what's your biggest
staffing headache right now? If it's [specific skill], I can tell you
exactly what we have on bench before I send anything."
```

## Objection: "We're on a hiring freeze"
```
"Understood. Freezes eventually thaw - would it make sense to get ahead
of that now? I can start building a pipeline of pre-screened candidates
so when the freeze lifts, you're not starting from zero."
```

## Objection: "Already have vendors"
```
"That makes sense. But here's the thing - we're already on [Prime]'s
approved vendor list. This is about making sure you know what bench we
have ready when speed matters. Can I send you our current TS/SCI inventory?"
```
