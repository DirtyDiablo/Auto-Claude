## Feature 21: Shared Library Extraction (Monorepo Prep)

### Feasibility: 7/10

**Verdict: SCOPE CREEP (for now)**

This is engineering hygiene that does not directly generate revenue. The most valuable code (LangGraph workflows) has already been copied into BD-Automation-Engine via `data/from_n8n_builder/langgraph/`.

### Key Concerns
- 35 files create their own `QdrantClient`
- ~123 occurrences of sqlite3/db access across 20+ files
- `git-filter-repo` for 3 repos is risky -- merging git histories means resolving path collisions
- Roadmap claims 1 day for the merge -- realistic is 2-3 weeks

### Recommendation
Do the internal library extraction within BD-Automation-Engine first (Phase 1 items like `libs/db-layer/`). Defer the 3-repo merge until there is a concrete need for cross-repo code sharing.

### Effort: XL (Extra Large)

## Feature 22: Mobile-Responsive Dashboard

### Feasibility: 8/10

**Verdict: ESSENTIAL -- highest ROI in Phase 5**

BD professionals operate at client sites, conferences, and in the field. Mobile access to contact dossiers and program briefs at the point of need is the difference between "tool I check at my desk" and "tool that makes me effective everywhere."

### Already Exists
- **117 responsive patterns** (Tailwind breakpoints `sm:`, `md:`, `lg:`) across 47 files
- Tailwind CSS foundation is in place

### Scope Recommendation
Focus on **5 critical mobile pages** (not all 48):
1. DailyPlaybook
2. Contacts
3. ProgramDetail
4. ExecutiveSummary
5. CallIntelligence

MindMap/KnowledgeGraph pages should be marked "tablet-only" (canvas-based rendering is fundamentally difficult on phone screens).

### Effort: M (Medium) for 5 pages, L for all 48

## Feature 23: Automated Weekly Intelligence Briefs

### Feasibility: 9/10 -- HIGHEST ROI, MOST FEASIBLE

**Verdict: ESSENTIAL -- ship this first**

This turns the platform from "pull-based tool" into "push-based intelligence service." Weekly briefs create a habit loop that drives retention.

### Already Built
- `MorningBriefingAgent` at `Engine8_Knowledge/agents/autonomous/morning_briefing.py` (527 lines, 11 nodes, 5-way parallel gather)
- `DailyBrief` dataclass with hiring_signals, pipeline_snapshot, due_actions, new_opportunities, contract_updates, priority_contacts
- Weekly pipeline at `data/from_n8n_builder/langgraph/bd_langgraph/pipeline_workflows.py` with `run_scheduled_weekly_pipeline()`
- Slack integration at `Engine8_Knowledge/integrations/slack_integration.py` (470 lines)

### What is Missing
- Email delivery (no email infrastructure -- need SES or SendGrid)
- Aggregation logic to roll up daily briefs into weekly summary
- Score change detection (delta tracking week-over-week)
- Template design for Slack Block Kit and HTML email

### Effort: M (Medium) -- core logic exists, work is aggregation + delivery

## Feature 24: CMMC Compliance & Security Audit Framework

### Feasibility: 6/10

**Verdict: ESSENTIAL but needs rescoping**

### What Exists
`src/security/audit_trail.py` -- append-only audit log with SHA-256 chain hashing, recording CRUD + export/share/search/login/logout actions. References "SOC 2 Type II and FedRAMP Moderate." Covers ~30% of CMMC Level 2 requirements.

### What is Missing for CMMC Level 2 (110 practices)
- **Access Control**: No RBAC, no MFA, no session controls
- **Media Protection**: No encryption-at-rest for SQLite databases or Qdrant
- **System & Comms Protection**: No TLS on internal APIs
- **Incident Response**: No IR plan or automated detection
- Full CMMC requires a C3PAO assessment (third-party audit) -- software is only part of the story

### Recommendation: Rescope
Do NOT attempt "CMMC Compliance" as a feature. Reframe as **"CUI Data Protection Hardening"**:
1. RBAC with JWT (depends on Phase 1 F3)
2. Encryption-at-rest (depends on Phase 3 F12 Supabase migration)
3. Expand audit trail to cover all 7 CMMC AU practices
4. Add session timeout and account lockout
5. Generate a CMMC gap analysis document

This scoped version is **L effort** (vs XL for full CMMC) and provides real value.

### Effort: XL (full CMMC), L (rescoped to CUI hardening)
